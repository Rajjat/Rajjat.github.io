# Rajjat Dadwal — Personal Academic Website

A custom, responsive GitHub Pages website for Rajjat Dadwal.

## Publish on GitHub Pages

1. Create a new public repository named exactly:
   `Rajjat.github.io`
2. Upload all files from this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Your website will be available at:
   https://Rajjat.github.io/

## Customize

- Replace `assets/Rajjat_Dadwal_CV.pdf` with your newest CV if needed.
- The profile photo currently uses the public GitHub avatar (`https://github.com/Rajjat.png`).
- Edit `index.html` for text, publications, links, etc.
- Edit `assets/style.css` for colors, spacing and visual design.

## Notes

The site is deliberately built as plain HTML/CSS/JavaScript so it is easy to maintain and works directly with GitHub Pages without a build system.
